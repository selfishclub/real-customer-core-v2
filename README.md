# real-customer-core-v2

> **찐팬 고객 = 이 사람이 있어서 비즈니스가 굴러가는 고객.**
> 많이 쓰는 사람이 아니라, **오래 남는 사람**입니다.

**고객의눈 코어**를 인터뷰로 세우는 Claude 스킬입니다.

---

## 왜 "많이 쓰는 사람"이 아닌가

| | 미용실 |
|---|---|
| 한 번 온 손님 | **2만 원** |
| 6년 다닌 단골 | 2만 원 × 두 달에 한 번 × 6년 = **70만 원** |

**객단가는 똑같이 2만 원입니다.** 비싸게 팔아서가 아니라 **오래 와서** 70만 원이 됐어요.

| 산출물 구성 | — | **나의 장점 · 찐팬 · 핵심 한 문장** |

## 고객의눈 코어 — 네 블록

| 블록 | 내용 |
|---|---|
| **A · 재료** | 나의 장점 — 하는 일 · **남이 나에게 묻는 것** · 반복해서 해결한 것 · 접근 가능한 것 |
| **B · 고객 언어** | 형태 · **변화(Before→After)** · 대안 · 대체 불가 · 핵심 한 문장 |
| **C · 주요 가치** | 그 변화를 **고객의 말로** 한 문장 |
| **D · 찐팬 페르소나** | **지불의사 × 지불능력 × 재구매 빈도수** |

**한 장으로 정리하면 세 덩어리입니다.**

```
나의 장점  |  찐팬  |  핵심 한 문장
```

### 왜 D에서 멈추나

D까지 나오면 **검증할 대상이 생긴 것**입니다.
핵심 상품은 검증 결과를 보고 정해야 안 틀려요.

```
real-customer-core-v2   →   real-customer-validation-v2   →   핵심 상품
고객의눈 코어                 가설이 맞는지 검증                검증 후 결정
```

## 네 종류의 사람

| | **지불능력 O** | 지불능력 X |
|---|---|---|
| **지불의사 O** | **찐팬 고객** — 우리를 영위하게 한다 | **응원단** — 응원만 해준다 |
| 지불의사 X | **스쳐 갈 고객** — 설득하다 지친다 | **행인** |

> **응원단이 가장 위험합니다.**
> 좋아요 누르고 댓글 달고 "나중에 꼭 살게요" 하는 사람들.
> 반응이 있어서 **잘 되고 있다고 착각하게 만들거든요.**

## 찐팬 판별 세 축

| 축 | 묻는 것 | 제품이 없는 경우 |
|---|---|---|
| **지불의사** | 지금도 불편해하나 · **돈을 낼 마음이 있나** | 나한테 물어본 적 있나 |
| **지불능력** | 낼 수 있나 · **결정권은 본인에게** | 비슷한 것에 돈을 쓴 적 있나 |
| **재구매 빈도수** | **한 번인가, 계속 쓸 일이 있나** | 한 번으로 끝날 문제인가 |

> **지불의사는 "불편한가"만으로 판정하지 않습니다.**
> 불편해도 돈 낼 생각이 없으면 응원단이에요.

**셋 다 O여야 찐팬.** 하나라도 X면 2×2 어느 칸인지 표시하고 멈춥니다.

| 어긋난 축 | 어느 칸 |
|---|---|
| 지불의사 X | 스쳐 갈 고객 · 행인 |
| **지불능력 X** | **응원단** |
| 재구매 빈도수 X | 1회성 고객 — 나쁜 게 아니라 설계가 달라짐 |

## 세 유형 모두 대응합니다

| 유형 | A에서 하는 일 | D에서 하는 일 |
|---|---|---|
| ① 제품이 있다 | 문의·리뷰·재방문에서 **검증 재료** | 실제 고객에서 찐팬 골라내기 |
| ② 계획만 있다 | 경험에서 **근거** | 가설로 세우기 |
| ③ **아무것도 없다** | **씨앗 발굴** | **이미 나에게 물어본 사람**을 후보로 |

> **나한테 물어본 사람은 지불의사가 확인된 사람입니다.**
> 제품이 없어도 그 사람이 첫 찐팬 후보가 됩니다.
