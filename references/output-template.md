# 고객의눈 코어 출력 템플릿

인터뷰가 끝나면 아래 양식으로 **한 장**을 만든다.

## 출력 규칙

1. **빈칸은 빈칸으로 둔다.** 채워지지 않은 칸을 AI가 메우지 않는다.
2. **마지막에 무엇이 비었는지 정리한다.**
3. 파일로 저장할지 물어본다. (`{이름}_고객의눈코어_v0.1.md`)
4. **핵심 상품과 검증으로 넘어가지 않는다.** 다음 단계 안내로 끝낸다.
